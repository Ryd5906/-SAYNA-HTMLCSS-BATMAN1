# Batman T4SU — one-page

Landing page sur l'univers de Batman, réalisée dans le cadre de la formation SAYNA.

**Démo en ligne :** <https://ryd5906.github.io/-SAYNA-HTMLCSS-BATMAN1/>

## Contenu

- Hero avec logo, accroche et boutons d'ancrage
- Section « Batman au cinéma » : Robert Pattinson, Christian Bale, Ben Affleck
- Section « Némésis » : Riddler, Joker, Darkseid
- Section « Alliés » : Alfred, Catwoman, James Gordon
- Section « Justice League »
- Carrousel multimédia de deux bandes-annonces (flèches, points, clavier, balayage tactile)
- Formulaire de contact avec validation de l'email et message de confirmation
- Citations et pied de page

## Technologies

HTML5, CSS3 (grid, flexbox, variables, responsive), JavaScript natif (DOM, événements, carrousel). Aucun framework, aucun build.

## Lancer le projet

Ouvrir `index.html` dans un navigateur, ou servir le dossier localement :

```bash
python -m http.server 8000
```

Puis ouvrir <http://localhost:8000>.
